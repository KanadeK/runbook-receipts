# Synthetic restore handover

This is a documentation fixture, not a production recovery procedure.

1. Read `config/backup.json` and verify the selected archive is the intended input.
2. Review `scripts/restore-plan.txt` with the receiving operator.
3. In a real system, perform and verify a restore in an isolated test environment.
4. Record a review only after checking the procedure and all declared dependencies.

No commands are executed by runbook-receipts.
